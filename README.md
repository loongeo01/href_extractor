A chrome extension that helps you get anchored hrefs in any webpage by scrolling. Other functions include setting a target area to only capture hrefs in that area, exporting to csv and more.

You can get the extension here: 
https://chromewebstore.google.com/detail/href-extractor/dpajlckfegpndieoggkabndjgnopeaim
